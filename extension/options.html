settings

Leave this as it is unless you run your own server. Use an https:// address, or http://localhost for a server on this computer. For a new https:// address, Chrome will ask you to let the extension talk to it.

When this is on, opening a GitHub repository or an npm package page sends that repository's address to the server, to look for an earlier check. When it is off, an address is sent only when you press Check before you run, or open this extension's popup.

What this extension sends

Only the address of a repository: the one you choose to check, and, if the setting above is on, the one on the page you are looking at. Nothing else: no other pages you visit, no cookies, no account details and no tracking.
