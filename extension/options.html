settings

Leave this as it is unless you run your own server. Use an https:// address, or http://localhost for a server on this computer. For a new https:// address, Chrome will ask you to let the extension talk to it.

When this is on, opening a GitHub repository or an npm package page sends that repository's address to the server, and to a public NEAR node that reads Airlock's verdict registry, to look for an earlier check. When it is off, an address is sent only when you press Check before you run, or open this extension's popup.

Guard AI agents in the browser

Some sites offer tools to AI agents in your browser (WebMCP), such as "swap tokens" or "sign transaction". With this on, checks every tool a site offers before an agent can see it:

  • A tool that slips instructions to the agent, or asks for a seed phrase or private key, is never shown to agents.
  • A tool that moves money or signs something waits for you: each time an agent calls it, you choose Allow or Block.
  • The extension's button shows what each page offered and what did.

It runs inside every https:// page you open, so Chrome will ask to let the extension read and change data on all sites. The checks happen on your computer: nothing about the pages is sent anywhere. WebMCP is new; Chrome turns it on for sites in its trial, or for all sites at chrome://flags/#enable-webmcp-testing.

What this extension sends

Only the address of a repository: the one you choose to check, and, if the setting above is on, the one on the page you are looking at. Nothing else: no other pages you visit, no cookies, no account details and no tracking.
