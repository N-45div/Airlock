# Todo API: take-home task

Thanks for taking the time to interview with us. This task should take about two hours.

## The task

Extend this small Express API so that todos can be marked done and filtered by status.
Add tests for both. Send us a link to your fork when you're finished.

## Setup

```sh
npm install
npm start
```

The API listens on http://localhost:3000.
