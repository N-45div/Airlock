Airlock · agent guard test page

A pretend crypto app that offers tools to AI agents

With WebMCP, a site can hand tools to the AI agent in your browser. This page offers five. Two are traps: one asks for a seed phrase, and one hides instructions to the agent in its description. Nothing here is real: there is no wallet, and nothing is sent anywhere.

Without Airlock, an agent sees all five. With the Airlock extension's agent guard on (Settings, then Guard AI agents in the browser), the traps never reach the agent, and the tools that move money wait for you to press Allow. WebMCP needs chrome://flags/#enable-webmcp-testing for now.
